# Litvak-Tuashi Design

אתר תדמית לסטודיו לעיצוב פנים של סיגל ליטבק ובן טואשי.

מחליף אפליקציית Base44 קיימת. הרקע וההנמקה ב-[DECISION.md](DECISION.md).

## מבנה

| תיקייה | מה יש בה |
|---|---|
| `web/` | אפליקציית Next.js — האתר הציבורי |
| `supabase/` | `schema.sql` — טבלאות, טריגרים ומדיניות RLS |
| `data/base44-export/` | ייצוא CSV של 6 הטבלאות מ-Base44 |
| `content/` | תוכן האתר הישן, עם סימון מה אמיתי ומה placeholder |
| `assets/images/` | 89 צילומי הפרויקטים (מחוץ ל-git — ראו למטה) |

## הרצה מקומית

```bash
cd web && npm install && npm run dev
```

בלי משתני סביבה האתר עולה, אבל רשת הפרויקטים ריקה. כדי לראות אותם — צרו
`web/.env.local` עם `NEXT_PUBLIC_SUPABASE_URL` ו-`NEXT_PUBLIC_SUPABASE_ANON_KEY`.

## Supabase

האתר קורא מ-Supabase שני דברים בלבד, בגישה ציבורית (anon) שמוגבלת ב-RLS:

- הטבלה `portfolio_projects` — הפרויקטים שמוצגים באתר.
- הדלי `portfolio` ב-Storage — צילומי הפרויקטים.

### עריכת תיק העבודות

אין ממשק עריכה באתר. מוסיפים ועורכים ב-Supabase Dashboard:
**Storage → portfolio** לתמונות, ו-**Table Editor → portfolio_projects** לפרטים.
פרויקט מוצג רק כש-`status` הוא `active`. האתר מתעדכן תוך שעה לכל היותר
(`revalidate` בעמוד הבית ובעמודי הפרויקטים), או מיד אחרי deploy.

### ⚠️ תוכנית חינמית

Supabase משהה פרויקט חינמי אחרי כשבוע בלי פעילות, ואז התמונות נשברות.
`web/vercel.json` מריץ פעם ביום Vercel Cron שקורא ל-`/api/keep-alive`, שעושה
שאילתה אחת. מומלץ להגדיר `CRON_SECRET` במשתני הסביבה ב-Vercel כדי שרק
Vercel Cron יוכל להפעיל אותו. זה פתרון עוקף — הפתרון המלא הוא תוכנית Pro.
בתוכנית החינמית אין גם גיבויים אוטומטיים.

## הפורטל — הוסר

עד נובמבר 2026 היה באתר פורטל לקוחות ומנהלים (התחברות, פרויקטי לקוחות,
ספריות קבצים, התראות, וניהול תיק העבודות). הוא הוסר מהאתר; הקוד נמצא
בהיסטוריה של git, בקומיט `cc17f84` ולפניו.

הסכמה, מדיניות ה-RLS והנתונים ב-Supabase **לא נגעו** — הטבלאות של הפורטל
עדיין שם, והחזרתו לא דורשת מיגרציה. החזרה תדרוש גם להפעיל מחדש את ספקי
ההתחברות (Google ו-Phone) ואת כתובת ה-Redirect `/auth/callback`.

## ⚠️ תמונות

`assets/images/` מוחרג מ-git בגלל גודלו (154MB), והוא **הגיבוי המקומי
היחיד** של צילומי העבודות. אין למחוק.

האתר מגיש את התמונות מהדלי `portfolio` ב-Supabase של הסטודיו. הכתובת
מוגדרת ב-`IMAGE_BASE` ב-`web/src/lib/images.ts`, ו-`next.config.ts` מתיר אותה
אוטומטית.
